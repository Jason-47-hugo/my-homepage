# 袁培淞 · 个人主页

> 🔗 **在线访问：<https://jason-47-hugo.github.io/my-homepage/>**

一个**单文件 HTML** 的个人主页，内置由大模型驱动的数字分身「问问我」——
访客可以直接和它对话，它会用第一人称介绍我的专业、学习方向、项目和兴趣。

---

## ✨ 功能亮点

- **AI 数字分身「问问我」**：接入 DeepSeek 大模型，能理解自然语言，回答关于我的问题
- **本地兜底**：模型超时或接口异常时，自动回退到页面内置的 31 条本地知识库，分身不会失联
- **行为边界**：事实类问题只依据知识库，不编造；隐私、他人评价、政治敏感、私生活四类问题一律拒答
- **交互细节**：打字机输出、语音朗读、快捷问题、深浅主题切换
- **分享与反馈**：分享卡片、匿名建议入口（Supabase）
- **响应式**：桌面双栏、移动端自适应

## 🧠 数字分身是怎么工作的

```
访客提问
   ↓  fetch（前端只调用自己的接口，不含任何密钥）
腾讯云函数 SCF（Node.js）· homepage-avatar-ai
   ↓  携带服务端环境变量里的 Key
DeepSeek API（deepseek-chat）
   ↓
回答返回页面（标注「依据：AI分身·DeepSeek」）
```

- **密钥安全**：DeepSeek API Key 只存放在云函数环境变量 `DEEPSEEK_API_KEY`，公开页面中零密钥
- **超时保护**：前端 15 秒超时，失败即回退本地知识库
- **行为约束**：通过系统提示词（角色 + 硬性规则 + 结构化知识库）控制回答范围

## 🛠 技术栈

| 部分 | 技术 |
| --- | --- |
| 前端 | 单文件 HTML / CSS / JavaScript（零构建、零依赖） |
| 托管 | GitHub Pages |
| 分身后端 | 腾讯云函数 SCF（Node.js 18，函数 URL 触发，已开启 CORS） |
| 大模型 | DeepSeek `deepseek-chat`（官方 OpenAI 兼容接口） |
| 反馈后台 | Supabase |

## 🚀 本地预览

不需要安装任何依赖，直接双击打开 `index.html` 即可；

也可以起一个本地服务（推荐，跨域请求更接近线上）：

```bash
python -m http.server 8000
# 然后访问 http://127.0.0.1:8000
```
