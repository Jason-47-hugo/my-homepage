个人主页进行中

我的第一个项目。用 Vibe Coding 的方式和 AI 一起做——从定方向、挑视觉风格，到一版一版地改，主意都是我自己拿的。

V2 阶段到现在一共 5 轮改动：加动效、重做视觉标识、手机端适配、给板块补上真实内容。其中有一轮做完发现不好看，退回来重新设计后重做了一遍——那一轮反而是我学到最多的。

技术上：单文件 HTML / CSS / JS，零构建依赖；用 Git 记录每一次改动。

Logo 方案对比页过程产物

为了定下个人标识，我一次画了 8 稿方案做成对比页，每稿都放在真实页面底色和真实导航栏尺寸下比较，最后才选定「行星 + 光环」这一稿。
