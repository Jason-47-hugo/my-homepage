关于我

现在在做什么

我现在在深圳。正在用 Vibe Coding 把想法做成产品项目——从需求到上线，一步步亲手实践；未来希望逐步学习计算机与 AI 的前沿技术，做出更多真正有用的东西。

为什么选计算机

当初选计算机这个专业，一是对计算机本身就感兴趣，二是看重它的就业前景。

生活里的我

学习上我比较佛系，但做事有自己的节奏；性格介于阳光开朗与沉默内敛之间。闲暇时喜欢打羽毛球或者打台球，也会去游泳；最喜欢的歌是《Best One》，小野道ono 和墨橙唱的。

不上课的时候

不上课的时候，我一般打打游戏、睡睡觉。手机上最常玩《崩坏：星穹铁道》，电脑上最喜欢《MiSide》（米塔）。

电影里最爱《肖申克的救赎》，番最爱《时光代理人》；想学吉他想了很久，就是还没真练起来。要推荐一本书的话，我推《不时轻声地以俄语遮羞的邻座艾莉同学》。平时写代码、做这个主页，都是在电脑上弄的。

Learning

正在学

  • 编程入门从零开始，目前能自己读懂并修改 HTML / CSS，正在继续往前学。

Projects

在做的东西

目前只有一个，但它是我从零走完的。

个人主页进行中

我的第一个项目。用 Vibe Coding 的方式和 AI 一起做——从定方向、挑视觉风格，到一版一版地改，主意都是我自己拿的。

V2 阶段做了 5 轮改动：加动效、重做视觉标识、手机端适配、给板块补上真实内容。其中有一轮做完发现不好看，退回来重新设计后重做了一遍——那一轮反而是我学到最多的。后来接上反馈后台，又加了数字分身、深色主题和分享卡。V4 又按访客的真实反馈把动效收敛、把「关于我」分段、让数字分身回答更详细，就是现在这一版。

技术上：单文件 HTML / CSS / JS，零构建依赖；用 Git 记录每一次改动。

Logo 方案对比页过程产物

为了定下个人标识，我一次画了 8 稿方案做成对比页，每稿都放在真实页面底色和真实导航栏尺寸下比较，最后才选定「行星 + 光环」这一稿。
